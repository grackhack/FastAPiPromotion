# Wildberries Promotion API Manager

Это мини-приложение позволяет управлять рекламными кампаниями Wildberries, включая работу с поисковыми кластерами.

## Возможности

- Получение списка рекламных кампаний
- Управление ставками поисковых кластеров
- Получение статистики по поисковым кластерам
- Работа с минус-фразами
- Получение списков активных и неактивных поисковых кластеров

## Установка

1. Клонируйте репозиторий
2. Установите зависимости: `pip install -r requirements.txt`
3. Настройте переменные окружения в файле `.env`
4. Запустите приложение: `uvicorn main:app --reload`

## Переменные окружения

- `WB_API_TOKEN` - токен API Wildberries (обязательно)
- `APP_HOST` - хост для запуска приложения (по умолчанию 0.0.0.0)
- `APP_PORT` - порт для запуска приложения (по умолчанию 8000)
- `APP_DEBUG` - режим отладки (по умолчанию False)
- `LOG_LEVEL` - уровень логирования (по умолчанию INFO)

## Использование

После запуска приложения API будет доступен по адресу `http://localhost:8000`

Документация к API автоматически генерируется и доступна по адресу `http://localhost:8000/docs`

## Эндпоинты

- `GET /campaigns` - получить список рекламных кампаний
- `POST /search-clusters/bids` - получить ставки поисковых кластеров
- `POST /search-clusters/set-bids` - установить ставки для поисковых кластеров
- `DELETE /search-clusters/remove-bids` - удалить ставки с поисковых кластеров
- `POST /search-clusters/stats` - получить статистику по поисковым кластерам
- `POST /search-clusters/minus-phrases` - получить список минус-фраз
- `POST /search-clusters/set-minus-phrases` - установить минус-фразы
- `POST /search-clusters/list` - получить списки активных и неактивных поисковых кластеров
